# Sentry

**AI assistant project · powered by ATOM**

Sentry is the user-facing identity of an AI-assistant project built on the ATOM project family.

This public repository is intentionally limited. Detailed architecture, source implementation, internal workflows, model/provider configuration, automation methods, credentials, infrastructure, private research, unreleased product specifications and other proprietary technical material are **not published here**.

## Product direction

The project explores AI-assisted interaction across desktop and mobile experiences, with interfaces designed for different user groups.

Public screenshots and product-level descriptions may be published selectively when they do not disclose proprietary implementation details.

## Development status

Active development continues privately.

No public document in this repository should be interpreted as a complete technical specification of the system.
